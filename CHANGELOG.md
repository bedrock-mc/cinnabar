# Changelog

Cinnabar's change history is generated from merged pull requests. Each PR title
is its brief change entry; one category label places it under New, Fixes,
Performance or Internal in the release notes.

- [Release history](https://github.com/cinnabar-mc/cinnabar/releases) contains the published changelogs.
- [Changes on dev](https://github.com/cinnabar-mc/cinnabar/commits/dev/) shows work since the latest release and earlier commit history.
- [Merged pull requests](https://github.com/cinnabar-mc/cinnabar/pulls?q=is%3Apr+is%3Amerged+base%3Adev) contain the implementation and validation details.

Write a short imperative PR title describing the resulting behavior. Apply
exactly one category label: `new`, `fix`, `performance` or `internal`.
The release workflow produces the entries from that record; do not add a
handwritten entry here for each PR.

Current scope and unfinished acceptance belong in [the roadmap](plan.md).
